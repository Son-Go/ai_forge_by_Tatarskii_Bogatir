# FAQ в кабинете менеджера

Карточка закрытого обращения загружает кандидата по менеджерскому API. Пока кандидат в очереди, панель проверяет статус каждые пять секунд. Для ручной проверки можно найти выдержку в справке, выбрать и подтвердить её, исправить вопрос и ответ, при необходимости указать продукт и редакцию. Статусы после одобрения, отклонения и снятия с публикации берутся из ответа Java.

Клиентский чат отображает утверждённый текст и ссылку на справку через обычные сообщения и источники, включая восстановление истории.

Изолированная страница `/tests/fixtures/faq-review.html` проверяет внешний вид панели с синтетическими данными. `pnpm check`, `pnpm test:api-browser` и `pnpm test:e2e` проверяют контракты, интерфейс и браузерные сценарии. Для проверки фоновой обработки и PostgreSQL используйте Java-интеграцию из [README бэкенда](../../backend/README.md#faq-из-ответов-менеджеров).
