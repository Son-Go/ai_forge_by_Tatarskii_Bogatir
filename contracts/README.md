# Контракты

- [Публичный OpenAPI](public.openapi.yaml) описывает сессию, поток чата, выбор позиции и опциональный черновик КП.
- [Внутренний OpenAPI](internal.openapi.yaml) описывает вызовы Java к FastAPI.
- [Примеры SSE](examples/) содержат синтетические данные. В `x-sse-events` указана схема JSON для каждого события. Блок завершается пустой строкой.

Поля, уточняющие архитектуру, зафиксированы в контрактах. Токен сессии передаётся в `softline_session`, версия каталога кодируется UUID, нарушенный `Origin` возвращает `403`.
