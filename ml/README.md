# Обучение и оценка

- `notebooks/` — Colab для обучения QLoRA и экспорта.
- `data/` — код подготовки выборки и инструкции по доступу.
- `evaluation/` — сценарии оценки, сравнение версий и метрики.

Порядок работы с моделями описан в [архитектуре](../ARCHITECTURE.md#7-ml-и-жизненный-цикл-модели). Исходные материалы команды находятся в соседней `info/`. Доступ к выборкам и весам настраивается в хранилищах команды.
