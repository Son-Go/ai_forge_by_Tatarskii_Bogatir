# Внутренний сервис ML

FastAPI, Pydantic, промпты и клиент Runpod относятся к этому модулю. Java вызывает `interpret` для извлечения требований и `compose` для пояснения по подтверждённым фактам. Форматы и сервисная авторизация описаны во [внутреннем OpenAPI](../contracts/internal.openapi.yaml).

`app/` предназначен для приложения, `tests/` — для проверок сервиса.
