# Журнал работы агентов

## 26 ноября 2026

- Цель. Привести каркас, контракты и план бэкенда к архитектуре команды.
- Начало работы. Сверены входная архитектура и файлы локального репозитория. Добавлено правило вести этот журнал.
- Обновлены `ARCHITECTURE.md` и `docs/backend-plan.md`. Уточнены поиск при отсутствии точного совпадения, передача сложных запросов и два вызова ML. `interpret` читает полную реплику, `compose` получает тексты фактов вместе с их идентификаторами.
- Вместо прежнего контракта добавлены публичный и внутренний OpenAPI, четыре примера SSE и каркас каталогов фронтенда, ML и инфраструктуры. В Spring Boot добавлены JDBC, Flyway и проверки состояния. Начальная миграция задаёт таблицы каталога, знаний и чата.
- Проверки. `mvn -f backend/pom.xml --offline compile` прошёл на Java 21. Команда `docker compose --env-file infra/.env.example -f infra/compose.yaml config --quiet` прошла. Миграция выполнена во временном PostgreSQL 17, сценарий проверил добавление снимков, карточки и запрет второго активного хода в сессии. Схемы и все 13 событий SSE проверены через JSON Schema.
- Статус. Архитектурный каркас готов. Реализация поиска, импорта и чата идёт отдельными этапами по плану. Сборка JAR в офлайн-режиме остановилась на отсутствующих зависимостях Maven Surefire.
