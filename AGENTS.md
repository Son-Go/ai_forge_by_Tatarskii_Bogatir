# Работа агентов с репозиторием

- Перед изменением кода прочитай [ARCHITECTURE.md](ARCHITECTURE.md), а при изменении API сверься с контрактами в `contracts/`.
- Для каждой задачи с изменением файлов добавь запись в [журнал работы агентов](docs/agent-work-log.md). Открой запись в начале работы и дополни её по мере выполнения. Сохраняй прежние записи.
- Запиши дату, цель, выполненные действия и затронутые файлы. Отметь решения, влияющие на поведение системы, команды проверки и их результаты. Если часть проверок или работы осталась, укажи конкретный блокер.
- Записывай сведения, достаточные для воспроизведения изменений и проверок. Исключай секреты, данные клиентов, тексты переписок и полный вывод команд с чувствительными данными.
