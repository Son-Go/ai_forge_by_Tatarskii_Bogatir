- Окружение. Доступны Node.js v24.22.3 и pnpm 11.25.0 из runtime Codex; PATH задаётся только процессам команд, без изменения системных настроек.
- Реализовано. Созданы приложение React/TypeScript/Vite, нейтральный адаптивный экран чата, карточки и источники, публичный HTTP-клиент, POST SSE, runtime-проверки ответов, reducer и контроллер диалога. Добавлены сессия, сохранение истории, восстановление через GET/polling, идемпотентный повтор доставки, повтор failed с новым ID без дублирования вопроса, частичные ответы и подтверждение изменившегося предложения. Текст при HTTP-отказе возвращается в редактор.
- Независимая разработка. MSW использует три существующих публичных SSE-примера и синтетические сценарии ошибок/обрывов/изменения предложения. Мок-история сохраняется в отдельном пространстве Web Storage. Режим `dev:mock` явно помечен; production не содержит обработчиков и service worker моков.
- Решения. Нативный fetch, eventsource-parser, локальный контроллер и reducer, без роутера и глобального state-фреймворка. TypeScript закреплён на 5.9.3 из-за совместимости генератора OpenAPI. Добавлен небольшой адаптер Source, attributes и обязательного status: генератор теряет required-only ветки исходной схемы. Контракт не изменялся. Параметры сессии и повторы сверяются с сервером; фактическая передача менеджеру не имитируется.
- Файлы. `frontend/`: package.json и lockfile, настройки TypeScript/Vite/ESLint/Vitest/Playwright, src/app, pages, features, entities, shared/api, mocks, тесты, public/mockServiceWorker.js, scripts/check-contract.mjs, README и docs/backend-questions.md. Эта запись дополнена с сохранением прежних записей.
- Проверки. С PATH runtime выполнен `pnpm check`: api:check, TypeScript, ESLint без предупреждений, 25 Vitest-тестов в 6 файлах, production-сборка. `pnpm test:e2e`: 8 успешных сценариев headless Chrome на десктопной и мобильной ширине, включая перезагрузку во время генерации. Проверены скриншоты обеих ширин, отсутствие горизонтального переполнения, безопасный текст/URL, повтор после ошибки, обрыв, выбор и восстановление истории. Production JS около 250 КБ, gzip около 79 КБ; реализация MSW и mockServiceWorker.js отсутствуют в dist. `git diff --check` прошёл; изменений в защищённых модулях нет.
- Ограничения. Реальный Backend/ML ещё не подключён; cookie, Origin и интеграционные вопросы перечислены в `frontend/docs/backend-questions.md`. Браузерный мок при перезагрузке во время обычной генерации сохраняет partial/failed вместо имитации фонового модельного процесса. Действующая авторизация серверных сессий моками не подтверждается.
