# Оставшиеся вопросы Backend/ML — 27.11.2026

Действующие операции реализованы по входным manager/public OpenAPI.
Точные границы: [backend-integration.md](backend-integration.md).

| Расхождение / неоднозначность | Принятое поведение Frontend / что нужно подтвердить |
| --- | --- |
| В общей contracts/ старый public без QuoteRequest, manager отсутствует | В frontend/contracts лежат неизменённые присланные копии и оба набора generated types; владельцу общей схемы нужно консолидировать их при интеграции |
| sender=manager описан в manager.ChatMessage и описании session/handoff, но не в public.Message | Узкий адаптер Message допускает только sender=manager при role=assistant; нужно синхронизировать публичную схему GET Session с фактическим ответом |
| QueueItem не содержит assigned_to, 404 деталей не различает отсутствие и неназначенность | Владение не угадывается по статусу, доступные действия ответа/resolve требуют успешного GET назначенного контекста |
| Нет total/cursor и серверного поиска/статусного фильтра | Фильтры только по текущей странице; следующий блок при 50 элементах может оказаться пустым. Глобальный поиск — отдельное расширение Backend при необходимости |
| Нет времени resolved_at/полного events | Не создаются даты/события из текущего статуса. Полный журнал требует нового согласованного формата |
| GET failed всё ещё не даёт user_message_id/client_message_id/retryable | Существующее восстановление использует подтверждённые ID своей вкладки, неизвестный повтор не угадывается |
| Bearer login/refresh endpoint не описан | Ручной ввод выданного токена, память до выхода/reload. Нужны процесс выдачи/ротации и совместная проверка прав на чужие/закрытые обращения |
| reason только document_review/off_catalog_order | Frontend не создаёт price/другие причины и не принимает решение об эскалации; поведение при отсутствующей цене остаётся решением Java |
| Счета/ИНН/КПП/НДС не описаны | Нет реальной генерации; согласовать DTO реквизитов, расчёт на Backend, формат/авторизацию/ошибки и безопасную выдачу. «Цена конечная» не определяет ставку НДС |

Дополнительно при живом прогоне: cookie/Origin/CHAT_PUBLIC_ORIGIN/HTTPS,
идемпотентность и конкуренция claim/reply/resolve, реакция клиента на менеджерские
реплики/закрытие, heartbeat/seq, лимиты/Retry-After и OFFER_CHANGED.
Генератор всё ещё требует узкого адаптера Source/attributes и обязательности status;
серверные схемы ради генератора не переписывались.
