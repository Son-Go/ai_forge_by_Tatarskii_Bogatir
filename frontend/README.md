# Веб-чат

Модуль команды фронтенда на React, TypeScript и Vite. Интерфейс использует публичный [OpenAPI](../contracts/public.openapi.yaml), читает события через `fetch` на POST и восстанавливает историю по GET после обрыва.

Сценарии для интеграции находятся в [примерах SSE](../contracts/examples/). Сборку `dist/` раздаёт Caddy.
